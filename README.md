# 内容发布交接 SOP 草稿

Use when 自媒体或电商团队把选题、素材核对、产品优惠审核、排期与错误修订的碎片笔记整理为内容发布交接 SOP，尤其缺少审批凭证或异常处置时。

## 适用场景

Use when 自媒体或电商团队把选题、素材核对、产品优惠审核、排期与错误修订的碎片笔记整理为内容发布交接 SOP，尤其缺少审批凭证或异常处置时。

## 安装与使用

```sh
git clone https://github.com/shuaige619/content-publish-sop.git
cd content-publish-sop
```

将此目录按宿主支持的方式登记为本地 Skill，或把 [SKILL.md](SKILL.md) 交给支持 Agent Skills 的助手读取。保留 `scripts/`、`references/` 等配套目录的相对位置；下载完成不代表宿主已加载。

需要能读取本地 Markdown 的 Agent 环境。其他工具与依赖以 SKILL.md 中的要求为准。

## 输入与输出

**输入：** 内容发布目标、平台、已有材料与交接约定。

**输出：** 发布交接 SOP、状态及待确认事项。

## 使用示例

```text
请使用 content-publish-sop 整理本次内容的发布交接，区分已确认条件与待确认条件，不实际发布。
```

以上是调用示例，不是已完成业务运行的记录。
